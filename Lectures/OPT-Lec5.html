1. Why Likelihood Belongs in an Optimization Course

Suppose a statistical model depends on an unknown parameter \(\theta\). After observing data, we need to choose a value of \(\theta\). A natural principle is:

Maximum-likelihood principle
Choose the parameter value that makes the observed data as plausible as possible under the assumed statistical model.
\[ \boxed{ \text{data} \longrightarrow \text{likelihood }L(\theta\mid x) \longrightarrow \max_{\theta} L(\theta\mid x). } \]

The likelihood therefore plays exactly the role of an objective function.

What we focus on today
Statistical estimation has one main broad question (out of many):
  1. How do we estimate the parameter?
This lecture focuses mainly on this question because it directly leads to optimization.

2. Likelihood Function

Let \(X_1,\ldots,X_n\) be a random sample from a model with density or probability mass function

\[ f(x\mid\theta), \qquad \theta\in\Theta. \]

The parameter space \(\Theta\) contains the possible values of \(\theta\). The parameter may be scalar or vector-valued.

Definition 1 — Likelihood
After the data \[ \mathbf{x}=(x_1,\ldots,x_n) \] have been observed, the likelihood function is the joint density / mass, viewed as a function of the parameter: \[ \boxed{L(\theta\mid\mathbf{x})=f(\mathbf{x}\mid\theta).} \] If the observations are independent, \[ \boxed{ L(\theta\mid\mathbf{x}) = \prod_{i=1}^{n}f(x_i\mid\theta). } \]
Very important distinction
In \(f(x\mid\theta)\), once \(\theta\) is fixed, \(x\) is the variable. In \(L(\theta\mid x)\), once the data are observed, \(\theta\) is the variable. The likelihood is therefore not a probability distribution over \(\theta\); it is an objective function measuring relative support for different parameter values.

2.1 A first likelihood: Normal mean

Example 1 — Two observations from \(N(\theta,1)\)
Suppose \[ X_1,X_2\stackrel{\mathrm{iid}}{\sim}N(\theta,1), \] and we observe \[ x_1=2,\qquad x_2=3. \] Then \[ \begin{aligned} L(\theta\mid2,3) &= f(2\mid\theta)f(3\mid\theta)\\ &= \frac{1}{2\pi} \exp\left\{ -\frac{(2-\theta)^2+(3-\theta)^2}{2} \right\}. \end{aligned} \]
The likelihood is maximized at \(\theta=2.5\), the sample mean of the observations \(2\) and \(3\).

3. Maximum Likelihood Estimation = Optimization

Definition 2 — Maximum likelihood estimator
\[ \boxed{ \widehat{\theta}_{\mathrm{MLE}} = \arg\max_{\theta\in\Theta} L(\theta\mid\mathbf{x}). } \]

Directly maximizing a product can be inconvenient. We therefore usually work with the log-likelihood

\[ \ell(\theta)=\log L(\theta\mid\mathbf{x}). \]

Since the logarithm is strictly increasing,

\[ \boxed{ \arg\max_{\theta}L(\theta\mid\mathbf{x}) = \arg\max_{\theta}\ell(\theta). } \]

For independent observations, the log also turns products into sums:

\[ \ell(\theta) = \sum_{i=1}^{n}\log f(x_i\mid\theta). \]
Optimization convention
Numerical optimization is often written as minimization. Define the negative log-likelihood \[ \boxed{Q(\theta)=-\ell(\theta).} \] Then \[ \boxed{ \widehat{\theta}_{\mathrm{MLE}} = \arg\min_{\theta\in\Theta}Q(\theta). } \]

3.1 Connection to Lecture 4: convexity and concavity

For maximization, the analogue of convexity is concavity. If \(\ell\) is twice differentiable, a sufficient condition for concavity is

\[ \nabla^2\ell(\theta)\preceq0. \]

Equivalently, \(-\ell(\theta)\) is convex.

Why this matters
If the log-likelihood is concave, any local maximizer is a global maximizer. If it is strictly concave, the maximizer is unique. This is exactly the convexity principle from Lecture 4, written for a maximization problem.

4. Bernoulli Example: MLE in Closed Form

Example 2 — Bernoulli parameter
Let \[ X_1,\ldots,X_n\stackrel{\mathrm{iid}}{\sim}\operatorname{Bernoulli}(p), \qquad 0\le p\le1. \]
\[ P(X_i=x_i)=p^{x_i}(1-p)^{1-x_i}, \qquad x_i\in\{0,1\}. \]

Hence

\[ \begin{aligned} L(p\mid\mathbf{x}) &= \prod_{i=1}^{n}p^{x_i}(1-p)^{1-x_i}\\ &= p^{\sum_i x_i}(1-p)^{n-\sum_i x_i}. \end{aligned} \]

Let \(S=\sum_{i=1}^{n}x_i\). Then

\[ \ell(p)=S\log p+(n-S)\log(1-p). \]

4.1 First-order condition

\[ \frac{d\ell}{dp} = \frac{S}{p} - \frac{n-S}{1-p}. \]

Setting the derivative equal to zero gives

\[ S(1-p)=p(n-S), \]

so

\[ \boxed{ \widehat p_{\mathrm{MLE}} = \frac{S}{n} = \frac1n\sum_{i=1}^{n}x_i = \bar x. } \]

4.2 Why is this a maximum?

\[ \frac{d^2\ell}{dp^2} = -\frac{S}{p^2} - \frac{n-S}{(1-p)^2} <0 \]

for interior values \(0 \lt p \lt 1\) when the sample contains both 0s and 1s. Thus the log-likelihood is strictly concave and the stationary point is the unique global maximum.

Boundary cases
If all observations are \(0\), the MLE is \(p=0\). If all observations are \(1\), the MLE is \(p=1\). In these cases the maximum occurs at the boundary, so an interior derivative condition is not the right tool.

5. Two-Parameter Exponential Example

Example 3 — Shifted exponential model
\[ f(x\mid\mu,\lambda) = \lambda e^{-\lambda(x-\mu)}, \qquad x\ge\mu,\quad\lambda>0. \]

For independent observations,

\[ \begin{aligned} L(\lambda,\mu\mid\mathbf{x}) &= \prod_{i=1}^{n}\lambda e^{-\lambda(x_i-\mu)}I(x_i\ge\mu)\\ &= \lambda^n \exp\left\{-\lambda\left(\sum_{i=1}^{n}x_i-n\mu\right)\right\} I\!\left(\mu\le \min_i x_i\right). \end{aligned} \]

5.1 Maximize with respect to \(\mu\)

For fixed \(\lambda>0\), the likelihood increases as \(\mu\) increases, but feasibility requires \(\mu\le\min_i x_i\). Therefore

\[ \boxed{ \widehat\mu_{\mathrm{MLE}} = X_{(1)} = \min_{1\le i\le n}X_i. } \]

5.2 Maximize with respect to \(\lambda\)

Substitute \(\widehat\mu=X_{(1)}\):

\[ \ell(\lambda) = n\log\lambda - \lambda\left(\sum_{i=1}^{n}X_i-nX_{(1)}\right). \] \[ \frac{d\ell}{d\lambda} = \frac{n}{\lambda} - \left(\sum_iX_i-nX_{(1)}\right). \]

Hence

\[ \boxed{ \widehat\lambda_{\mathrm{MLE}} = \frac{n}{ \sum_{i=1}^{n}X_i-nX_{(1)} }. } \]

Also

\[ \frac{d^2\ell}{d\lambda^2} = -\frac{n}{\lambda^2}<0. \]
A new phenomenon
Here the parameter \(\mu\) changes the support of the distribution. Its MLE occurs at a boundary, rather than from solving \(\partial\ell/\partial\mu=0\).

6. Linear Regression as Likelihood Optimization

This section is especially important because it connects today's optimization viewpoint to the Regression course that follows.

Gaussian linear model
Let \(Y_i\) be the response and \[ \mathbf{x}_i=(x_{i1},\ldots,x_{ip})^\top\in\mathbb{R}^p \] the predictor vector. Assume \[ Y_i=\mathbf{x}_i^\top\boldsymbol\beta+\varepsilon_i, \qquad \varepsilon_i\stackrel{\mathrm{iid}}{\sim}N(0,\sigma^2). \] In matrix form, \[ \boxed{ \mathbf{Y} = X\boldsymbol\beta+\boldsymbol\varepsilon, \qquad \boldsymbol\varepsilon\sim N_n(\mathbf0,\sigma^2I_n). } \]

6.1 Likelihood and log-likelihood

\[ \boxed{ \ell(\boldsymbol\beta,\sigma^2) = -\frac n2\log(2\pi) -\frac n2\log(\sigma^2) -\frac{1}{2\sigma^2} (\mathbf{y}-X\boldsymbol\beta)^\top (\mathbf{y}-X\boldsymbol\beta). } \]

6.2 MLE of the regression coefficient

For fixed \(\sigma^2\), maximizing the log-likelihood is equivalent to minimizing

\[ \boxed{ \|\mathbf{y}-X\boldsymbol\beta\|_2^2. } \]
Major connection
Under Gaussian errors, \[ \boxed{ \text{maximum likelihood} \quad\Longleftrightarrow\quad \text{least squares}. } \]
\[ \nabla_{\boldsymbol\beta}\ell = \frac{1}{\sigma^2}X^\top(\mathbf{y}-X\boldsymbol\beta). \]

The first-order condition gives

\[ X^\top\mathbf{y} - X^\top X\widehat{\boldsymbol\beta} = 0. \]

If \(X^\top X\) is invertible,

\[ \boxed{ \widehat{\boldsymbol\beta}_{\mathrm{MLE}} = (X^\top X)^{-1}X^\top\mathbf{y}. } \]

6.3 MLE of \(\sigma^2\)

\[ -\frac{n}{2\sigma^2} + \frac{ (\mathbf{y}-X\boldsymbol\beta)^\top(\mathbf{y}-X\boldsymbol\beta) }{ 2\sigma^4 } = 0. \]

Hence

\[ \boxed{ \widehat{\sigma}^2_{\mathrm{MLE}} = \frac{ \|\mathbf{y}-X\widehat{\boldsymbol\beta}\|_2^2 }{n}. } \]
For the later Regression course
The MLE uses denominator \(n\). The familiar unbiased estimator of \(\sigma^2\) uses a degrees-of-freedom correction. That distinction belongs to inference rather than optimization.
What if \(X^\top X\) is singular?
Then the inverse formula cannot be used and the coefficient vector need not be unique. This motivates regularization: modify the optimization objective so that a stable unique solution is selected.

7. Penalized Regression = Regularized Optimization

\[ \boxed{ Q(\boldsymbol\beta) = -\log L(\boldsymbol\beta\mid\mathbf y) + P(\boldsymbol\beta). } \]

The penalty \(P(\boldsymbol\beta)\) discourages parameter values that are too large or complex.

Example 4 — Ridge regression
Use \[ P(\boldsymbol\beta) = \frac{\lambda}{2}\boldsymbol\beta^\top\boldsymbol\beta, \qquad \lambda>0. \] Ignoring constants and an overall positive scaling, \[ \boxed{ Q(\boldsymbol\beta) = \frac12\|\mathbf y-X\boldsymbol\beta\|_2^2 + \frac{\lambda}{2}\|\boldsymbol\beta\|_2^2. } \]

7.1 Derivation of the ridge solution

\[ \nabla Q(\boldsymbol\beta) = -X^\top\mathbf y + X^\top X\boldsymbol\beta + \lambda\boldsymbol\beta. \]

Set the gradient to zero:

\[ (X^\top X+\lambda I_p)\widehat{\boldsymbol\beta} = X^\top\mathbf y. \]

Thus

\[ \boxed{ \widehat{\boldsymbol\beta}_{\mathrm{ridge}} = (X^\top X+\lambda I_p)^{-1}X^\top\mathbf y. } \]

7.2 Why does ridge have a unique solution?

\[ \nabla^2 Q = X^\top X+\lambda I_p. \]

For any nonzero \(\mathbf a\in\mathbb R^p\),

\[ \begin{aligned} \mathbf a^\top(X^\top X+\lambda I_p)\mathbf a &= \|X\mathbf a\|_2^2+\lambda\|\mathbf a\|_2^2\\ &>0. \end{aligned} \]
Connection back to Lecture 4
The ridge objective is strongly convex for \(\lambda>0\). Therefore it has a unique global minimizer, even when \(X^\top X\) itself is singular.

8. When No Closed-Form MLE Exists

Many likelihood problems lead to equations that cannot be solved analytically.

Example 5 — Gamma shape parameter
Let \[ X_1,\ldots,X_n\stackrel{\mathrm{iid}}{\sim}\operatorname{Gamma}(\alpha,1), \qquad \alpha>0. \] Then \[ L(\alpha\mid\mathbf x) = \frac{e^{-\sum_i x_i}}{\Gamma(\alpha)^n} \prod_{i=1}^{n}x_i^{\alpha-1}. \]
\[ \ell(\alpha) = -n\log\Gamma(\alpha) + (\alpha-1)\sum_{i=1}^{n}\log x_i - \sum_{i=1}^{n}x_i. \] \[ \frac{d\ell}{d\alpha} = -n\frac{\Gamma'(\alpha)}{\Gamma(\alpha)} + \sum_{i=1}^{n}\log x_i. \]

Define the digamma function

\[ \psi(\alpha) = \frac{\Gamma'(\alpha)}{\Gamma(\alpha)}. \]

The MLE must solve

\[ \boxed{ \psi(\alpha) = \frac1n\sum_{i=1}^{n}\log x_i. } \]

There is no elementary closed-form inverse of \(\psi\), so the parameter cannot be isolated by ordinary algebra.

8.1 But the objective is still well behaved

\[ \frac{d^2\ell}{d\alpha^2} = -n\psi_1(\alpha), \]

where \(\psi_1(\alpha)\) is the trigamma function. Since \(\psi_1(\alpha)>0\) for \(\alpha>0\),

\[ \boxed{ \frac{d^2\ell}{d\alpha^2}<0. } \]

Thus the log-likelihood is strictly concave: the optimum is unique, but it is not available in closed form.

This is the bridge to Lecture 6
We now have exactly the situation that motivates numerical optimization:
  • we know the objective;
  • we know the gradient;
  • we know the curvature;
  • a unique optimum exists;
  • but algebra cannot give the optimizer explicitly.
Next we develop iterative methods such as gradient descent/ascent and Newton--Raphson.
Preview of the numerical idea
Instead of solving once for \(\widehat\theta\), construct a sequence \[ \theta_0,\theta_1,\theta_2,\ldots \] whose objective values improve until the iterates approach the optimum.
