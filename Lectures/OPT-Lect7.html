1. Why Do We Need Another Algorithm?

For a differentiable objective \(f(\theta)\), Newton's method (Lecture 6) uses a second-order Taylor approximation. Its one-dimensional update is

\[ \theta_{k+1}=\theta_k-\frac{f'(\theta_k)}{f''(\theta_k)}. \]

For a vector parameter, this becomes

\[ \boldsymbol\theta_{k+1}=\boldsymbol\theta_k- [\nabla^2 f(\boldsymbol\theta_k)]^{-1}\nabla f(\boldsymbol\theta_k). \]
Newton–Raphson is powerful, but it has limitations
  • For high-dimensional problems, constructing the Hessian and solving a linear system can be expensive.
  • If the Hessian is singular or indefinite, the raw Newton direction may be undefined or may fail to improve the objective.
  • In nonconvex/nonconcave problems, the starting value can strongly influence the result. Even strict concavity does not guarantee convergence of undamped Newton from every start.

This motivates gradient methods: use first derivatives only. The trade-off is that gradient methods may need more iterations, and their performance depends heavily on the step size.

2. Deriving Gradient Ascent from a Local Model

Suppose our aim is to maximize a differentiable function \(f(\theta)\). Near the current point \(\theta_k\), the second-order Taylor expansion is

\[ f(\theta)\approx f(\theta_k)+f'(\theta_k)(\theta-\theta_k) +\frac12 f''(\theta_k)(\theta-\theta_k)^2. \]

In the spirit of your notes, instead of computing \(f''(\theta_k)\), we construct a concave quadratic surrogate with a chosen curvature \(-1/t\), where \(t>0\):

\[ q_k(\theta)=f(\theta_k)+f'(\theta_k)(\theta-\theta_k) -\frac{1}{2t}(\theta-\theta_k)^2. \]
What is the approximation doing?
The linear term follows the local slope of \(f\). The negative quadratic term prevents us from jumping infinitely far along that slope. The positive number \(t\) controls how far the next step can move. This is a model we choose, not an assertion that the true Hessian is exactly \(-1/t\).

Maximize the easy function \(q_k\) by setting its derivative to zero:

\[ \frac{dq_k}{d\theta}=f'(\theta_k)-\frac{\theta-\theta_k}{t}=0. \]

Solving for its maximizer produces the next iterate:

Gradient-ascent update
\[ \boxed{\theta_{k+1}=\theta_k+t f'(\theta_k),\qquad t>0.} \] The method moves in the direction of increasing the objective. If \(f'(\theta_k)>0\), move right; if \(f'(\theta_k)<0\), move left.

2.1 The algorithm

  1. Choose an initial point \(\theta_0\) and step size \(t>0\).
  2. Compute the slope \(f'(\theta_k)\).
  3. Update \(\theta_{k+1}=\theta_k+t f'(\theta_k)\).
  4. Repeat until the gradient is sufficiently small, the step is sufficiently small, or a maximum iteration count is reached.
Stopping safely
A small change \(|\theta_{k+1}-\theta_k|\) does not always certify optimality, especially if \(t\) is tiny. Check both the gradient and whether the objective has stabilized. Also limit the number of iterations.

3. Gradient Descent and the Steepest Direction

If the problem is to minimize \(F(\theta)\) rather than maximize \(f(\theta)\), apply ascent to \(-F\). This changes the plus sign into a minus sign:

Gradient-descent update
\[ \boxed{\theta_{k+1}=\theta_k-t F'(\theta_k),\qquad t>0.} \] In several dimensions, \[ \boxed{\mathbf x_{k+1}=\mathbf x_k-t\nabla F(\mathbf x_k).} \]

3.1 Why the negative gradient?

For a differentiable \(F\), moving from \(\mathbf x\) in a unit direction \(\mathbf d\) has first-order change

\[ F(\mathbf x+\varepsilon\mathbf d)\approx F(\mathbf x)+ \varepsilon\nabla F(\mathbf x)^\top\mathbf d. \]

By the Cauchy–Schwarz inequality, among unit directions the most negative directional derivative occurs at

\[ \boxed{\mathbf d=-\frac{\nabla F(\mathbf x)}{\|\nabla F(\mathbf x)\|_2}}, \quad \nabla F(\mathbf x)\ne\mathbf0. \]

Thus \(-\nabla F\) is the direction of steepest local decrease in Euclidean geometry. The step size still determines how far to travel.

Connection to maximum likelihood
If \(\ell(\theta)\) is a log-likelihood and \(F(\theta)=-\ell(\theta)\), then \[ \underbrace{\theta_{k+1}=\theta_k+t\ell'(\theta_k)}_{\text{maximize log-likelihood}} \quad\Longleftrightarrow\quad \underbrace{\theta_{k+1}=\theta_k-tF'(\theta_k)}_{\text{minimize negative log-likelihood}}. \] They are two views of the same algorithm.

4. Step Size: When Does Gradient Descent Work?

A gradient tells us the right local direction, not the right distance. To see why step size matters, minimize

\[ F(x)=\frac12(x-1)^2, \qquad F'(x)=x-1. \]

The descent update is

\[ x_{k+1}=x_k-t(x_k-1). \]

Subtract the minimizer \(x^*=1\):

\[ x_{k+1}-1=(1-t)(x_k-1) \quad\Longrightarrow\quad x_k-1=(1-t)^k(x_0-1). \]
Thus the iterates converge to \(1\) exactly when \(\boxed{0<t<2}\) for this particular quadratic. For \(t=1\), convergence occurs in one step; for \(1<t<2\), the iterates oscillate while approaching the minimum; for \(t>2\), the iterates diverge.

4.1 A general sufficient step-size condition

If \(F\) has an \(L\)-Lipschitz gradient, meaning that

\[\|\nabla F(\mathbf x)-\nabla F(\mathbf y)\|_2\le L\|\mathbf x-\mathbf y\|_2,\]

then it obeys the descent lemma:

\[ F(\mathbf y)\le F(\mathbf x)+\nabla F(\mathbf x)^\top(\mathbf y-\mathbf x) +\frac{L}{2}\|\mathbf y-\mathbf x\|_2^2. \]

Substitute \(\mathbf y=\mathbf x-t\nabla F(\mathbf x)\):

\[ F(\mathbf x_{k+1})\le F(\mathbf x_k)-t\left(1-\frac{Lt}{2}\right) \|\nabla F(\mathbf x_k)\|_2^2. \]

Consequently, any \(0<t<2/L\) guarantees a decrease whenever the gradient is nonzero. This does not by itself promise convergence to a finite global optimizer without additional assumptions. For a convex objective and standard smoothness/solution assumptions, appropriate fixed steps yield convergence in objective value.

6. Worked Example: Gradient Ascent for a Cauchy Likelihood

Return to the nonconcave Cauchy model from Lecture 6. For independent observations from a Cauchy distribution with location \(\mu\) and scale \(1\),

\[ f(x\mid\mu)=\frac{1}{\pi[1+(x-\mu)^2]}. \]

The log-likelihood for observations \(x_1,\ldots,x_n\) is

\[ \boxed{\ell(\mu)=-n\log\pi-\sum_{i=1}^n\log(1+(x_i-\mu)^2).} \]

Differentiate with respect to \(\mu\):

\[ \boxed{\ell'(\mu)=2\sum_{i=1}^{n}\frac{x_i-\mu}{1+(x_i-\mu)^2}.} \]

Unlike Newton's method, gradient ascent uses only this score. With step size \(t>0\),

Cauchy location update
\[ \boxed{\mu_{k+1}=\mu_k+2t\sum_{i=1}^n\frac{x_i-\mu_k}{1+(x_i-\mu_k)^2}.} \]

A sensible starting value is the sample median, because the Cauchy mean is undefined. Nevertheless, different starts can converge to different stationary points because the finite-sample log-likelihood need not be concave.

What a student should notice
  • Gradient ascent with a sufficiently small step can increase the log-likelihood near a point with nonzero score.
  • With a large step, it may overshoot, oscillate, or decrease the log-likelihood.
  • For a nonconcave objective, convergence to a stationary point does not certify the global MLE. Compare final likelihood values across starts.

8. Gradient Methods in Higher Dimensions

Now let the parameter be \(\boldsymbol\theta=(\theta_1,\ldots,\theta_p)^\top\). The first-order Taylor expansion is

\[ f(\boldsymbol\theta_k+\mathbf d)\approx f(\boldsymbol\theta_k)+\nabla f(\boldsymbol\theta_k)^\top\mathbf d. \]

Choose a concave quadratic local model for maximization:

\[ q_k(\boldsymbol\theta_k+\mathbf d)=f(\boldsymbol\theta_k) +\nabla f(\boldsymbol\theta_k)^\top\mathbf d-\frac{1}{2t}\|\mathbf d\|_2^2. \]

Differentiate with respect to \(\mathbf d\), set it to zero, and obtain \(\mathbf d=t\nabla f(\boldsymbol\theta_k)\). Hence,

\[ \boxed{\begin{aligned} \text{Gradient ascent: } &\boldsymbol\theta_{k+1}=\boldsymbol\theta_k+t\nabla f(\boldsymbol\theta_k),\\ \text{Gradient descent: } &\boldsymbol\theta_{k+1}=\boldsymbol\theta_k-t\nabla F(\boldsymbol\theta_k). \end{aligned}} \]
A practical choice: sum versus average
Likelihood derivatives often sum over all \(n\) observations. For code, it is frequently convenient to optimize the average negative log-likelihood. This divides the gradient by \(n\) but leaves its minimizer unchanged. The effective learning rate then has a more stable scale across datasets. The Python and interactive logistic example below use the average objective; the mathematical score displayed next uses the original sum.

9. Logistic Regression: A Likelihood We Cannot Solve Explicitly

9.1 Why not use linear regression for a binary response?

Suppose \(Y_i\in\{0,1\}\). Linear regression can produce predictions below \(0\) or above \(1\), which cannot be interpreted as probabilities. Logistic regression instead models

\[ \Pr(Y_i=1\mid\mathbf x_i)=p_i=\sigma(\eta_i),\qquad \sigma(z)=\frac{1}{1+e^{-z}},\qquad \eta_i=\beta_0+\mathbf x_i^\top\boldsymbol\beta. \]

The sigmoid maps every real score \(\eta_i\) into the interval \((0,1)\). It also makes the log-odds linear:

\[ \boxed{\log\frac{p_i}{1-p_i}=\beta_0+\mathbf x_i^\top\boldsymbol\beta.} \]
The sigmoid transforms an unrestricted linear score into a valid probability.
When \(p=0.5\), the linear score is zero, giving a straight decision boundary in two dimensions.

9.2 Likelihood and log-likelihood

Assume conditional independence and \(Y_i\mid\mathbf x_i\sim\mathrm{Bernoulli}(p_i)\). Then

\[ L(\boldsymbol\beta)=\prod_{i=1}^{n}p_i^{y_i}(1-p_i)^{1-y_i}. \]

Include an intercept in an augmented predictor \(\widetilde{\mathbf x}_i=(1,\mathbf x_i^\top)^\top\) and in \(\widetilde{\boldsymbol\beta}=(\beta_0,\boldsymbol\beta^\top)^\top\). To simplify notation, write \(X\) for the augmented design matrix and \(\beta\) for the complete coefficient vector. Using \(\eta_i=\mathbf x_i^\top\boldsymbol\beta\),

\[ \boxed{\ell(\boldsymbol\beta)=\sum_{i=1}^{n}\left[y_i\eta_i-\log(1+e^{\eta_i})\right].} \]

We need an algorithm because the score equations are nonlinear in \(\boldsymbol\beta\).

9.3 Derive the gradient (score)

First note that \(\frac{d}{d\eta}\log(1+e^\eta)=\frac{e^\eta}{1+e^\eta}=\sigma(\eta)\). Writing the log-likelihood as a sum of a linear term and a nonlinear term,

\[ \ell(\boldsymbol\beta)=\sum_{i=1}^{n}y_i\sum_{j}x_{ij}\beta_j -\sum_{i=1}^{n}\log\left(1+e^{\sum_j x_{ij}\beta_j}\right). \]

Differentiate with respect to any one coefficient \(\beta_j\):

\[ \begin{aligned} \frac{\partial\ell}{\partial\beta_j} &=\sum_{i=1}^{n}y_ix_{ij}-\sum_{i=1}^{n} \frac{e^{\eta_i}}{1+e^{\eta_i}}x_{ij}\\ &=\sum_{i=1}^{n}x_{ij}(y_i-p_i). \end{aligned} \]

Collecting the coordinate derivatives into a vector:

Logistic regression score
\[ \boxed{\nabla\ell(\boldsymbol\beta)=X^\top(\mathbf y-\mathbf p),\qquad \mathbf p=\sigma(X\boldsymbol\beta).} \] This gives an immediate gradient-ascent update using only matrix multiplication and the sigmoid.

9.4 Hessian and concavity

Since \(\sigma'(\eta)=\sigma(\eta)[1-\sigma(\eta)]\), differentiating the score once more gives the individual Hessian entries

\[ \frac{\partial^2\ell}{\partial\beta_j\partial\beta_k} =-\sum_{i=1}^{n}x_{ij}x_{ik}p_i(1-p_i). \]

Collect these terms into a matrix:

\[ \boxed{\nabla^2\ell(\boldsymbol\beta)=-X^\top W X,\quad W=\operatorname{diag}\big(p_i(1-p_i)\big).} \]

For any vector \(\mathbf v\),

\[ \mathbf v^\top\nabla^2\ell(\boldsymbol\beta)\mathbf v =-\sum_{i=1}^n p_i(1-p_i)(\mathbf x_i^\top\mathbf v)^2\le0. \]

Thus \(\ell\) is concave and the negative log-likelihood is convex. When the design has full column rank, the Hessian is negative definite at finite coefficients; however, complete separation can still prevent the existence of a finite MLE. In our interactive example the classes overlap, so the maximizer is finite.

9.5 Gradient ascent for logistic regression

\[ \boxed{\boldsymbol\beta_{k+1}=\boldsymbol\beta_k+t X^\top(\mathbf y-\mathbf p_k),\qquad \mathbf p_k=\sigma(X\boldsymbol\beta_k).} \]

For the average log-likelihood used in the practical, the update becomes

\[ \boxed{\boldsymbol\beta_{k+1}=\boldsymbol\beta_k+\frac{t}{n}X^\top(\mathbf y-\mathbf p_k).} \]
  1. Start at \(\boldsymbol\beta_0=\mathbf0\), so initially \(p_i=0.5\).
  2. Choose \(t>0\).
  3. Calculate probabilities, then the gradient.
  4. Update the coefficients; repeat until convergence.
Prediction and decision rule
After fitting, predict \(\widehat p=\sigma(\beta_0+\mathbf x^\top\beta)\). If the classification threshold is \(0.5\), predict class \(1\) when \(\widehat p\ge0.5\). At the decision boundary, class probabilities are equal: \[p=1-p \quad\Longrightarrow\quad p=0.5 \quad\Longrightarrow\quad\beta_0+\mathbf x^\top\beta=0.\] This is a hyperplane: a direct connection to Lecture 4.

11. Python Practical — The Uploaded Code Revisited

Your R script used a Cauchy likelihood with the three starts median, 7, and 19, and step sizes such as \(t=0.3\) and \(t=1\). The companion Python script reproduces the algorithmic comparison with NumPy, SciPy, and Matplotlib. It uses a fixed Cauchy teaching sample so that students reliably see multiple local optima.

11.1 The core Cauchy loop

def cauchy_score(mu, x):
    z = x - mu
    return np.sum(2.0 * z / (1.0 + z*z))

mu = float(np.median(x))  # robust initial value
t = 0.3
for k in range(100):
    next_mu = mu + t * cauchy_score(mu, x)
    if abs(next_mu - mu) < 1e-8:
        mu = next_mu
        break
    mu = next_mu

11.2 Logistic regression in NumPy

With \(\mathbf y\) stored as a one-dimensional array, a numerically stable sigmoid and objective produce a direct implementation:

from scipy.special import expit

beta = np.zeros(X.shape[1])  # X includes the intercept column
for k in range(2500):
    prob = expit(X @ beta)
    grad = X.T @ (prob - y) / len(y)  # average negative log-lik. gradient
    beta = beta - 0.2 * grad         # gradient descent
Correction to the uploaded scratch notebook
In the uploaded notebook, \(y\) is reshaped to \((n,1)\) while predictions are shape \((n,)\). In NumPy, operations such as y - pred then broadcast to an unintended \((n,n)\) array. For the corrected version, labels and predictions are both 1D. I also standardize the input features using training-set-only statistics, and use scipy.special.expit and np.logaddexp for numerical stability. Those are implementation corrections, not new statistical assumptions.
