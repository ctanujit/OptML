Introduction to Optimization (MATH-224) - Lecture 4

Convex Analysis for Optimization: Convex Sets and Convex Functions
by Tanujit Chakraborty
Big picture
Convex analysis gives us a geometric language for optimization. The central idea is simple: if we take two feasible points and move along the straight line segment joining them, do we remain feasible? From this one idea come convex sets, norm balls, polyhedra, convex hulls, cones, and the definition of a convex function.

1. Convex Combinations and Convex Sets

Definition 1 — Convex combination
Given points \(\mathbf{x}_1,\ldots,\mathbf{x}_k\in\mathbb{R}^n\), a point \[ \mathbf{z}=\lambda_1\mathbf{x}_1+\cdots+\lambda_k\mathbf{x}_k \] is called a convex combination if \[ \lambda_i\ge 0\quad\text{for all }i, \qquad \sum_{i=1}^{k}\lambda_i=1. \]

The coefficients \(\lambda_i\) can be interpreted as nonnegative weights that add up to one.

Two-point form

For two points \(\mathbf{x},\mathbf{y}\), write

\[ \mathbf{z} = \lambda_1\mathbf{x}+\lambda_2\mathbf{y}, \qquad \lambda_1+\lambda_2=1. \]

Set \(\lambda=\lambda_1\). Then \(\lambda_2=1-\lambda\). Since both coefficients are nonnegative,

\[ \lambda\ge0, \qquad 1-\lambda\ge0, \]

and therefore

\[ \boxed{0\le\lambda\le1.} \]

Hence every convex combination of two points has the form

\[ \boxed{ \mathbf{z} = \lambda\mathbf{x}+(1-\lambda)\mathbf{y}, \qquad \lambda\in[0,1]. } \]
Geometric interpretation
As \(\lambda\) varies from \(0\) to \(1\), the point \(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\) traces the line segment joining \(\mathbf{y}\) and \(\mathbf{x}\).
All two-point convex combinations lie on the segment between the points.
If \(\mathbf{x}=(1,0)^\top\) and \(\mathbf{y}=(0,1)^\top\), then \(\mathbf{z}=(\lambda,1-\lambda)^\top\).
Definition 2 — Convex set
A set \(X\subseteq\mathbb{R}^n\) is convex if, for every \(\mathbf{x},\mathbf{y}\in X\) and every \(\lambda\in[0,1]\), \[ \boxed{ \lambda\mathbf{x}+(1-\lambda)\mathbf{y}\in X. } \]

Equivalently, a convex set contains every line segment joining any two of its points.

Proof strategy
To prove convexity, start with arbitrary \(\mathbf{x},\mathbf{y}\in X\) and arbitrary \(\lambda\in[0,1]\), then verify that \(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\) still satisfies the defining constraints of \(X\). To disprove convexity, one counterexample is enough.

Example 1: the first quadrant

Consider

\[ X_1= \left\{ \mathbf{x}\in\mathbb{R}^2: x_1\ge0,\;x_2\ge0 \right\}. \]

Take arbitrary

\[ \mathbf{x}= \begin{pmatrix}x_1\\x_2\end{pmatrix}, \qquad \mathbf{y}= \begin{pmatrix}y_1\\y_2\end{pmatrix} \in X_1. \]

Then \(x_1,x_2,y_1,y_2\ge0\). For \(\lambda\in[0,1]\),

\[ \mathbf{z} = \lambda\mathbf{x}+(1-\lambda)\mathbf{y} = \begin{pmatrix} \lambda x_1+(1-\lambda)y_1\\ \lambda x_2+(1-\lambda)y_2 \end{pmatrix}. \]

Every coefficient and every coordinate is nonnegative, so both coordinates of \(\mathbf{z}\) are nonnegative. Thus

\[ \boxed{\mathbf{z}\in X_1}, \]

and therefore \(X_1\) is convex.

Example 2: a nonconvex set

Consider

\[ X_2= \left\{ \mathbf{x}\in\mathbb{R}^2: x_1x_2\ge0 \right\}. \]

This set consists of the first and third quadrants, including the axes. Choose

\[ \mathbf{x}= \begin{pmatrix}2\\1\end{pmatrix}, \qquad \mathbf{y}= \begin{pmatrix}-1\\-2\end{pmatrix}. \]

Both points belong to \(X_2\), but their midpoint is

\[ \frac12\mathbf{x}+\frac12\mathbf{y} = \begin{pmatrix} 1/2\\ -1/2 \end{pmatrix}, \]

whose coordinate product is \(-1/4<0\). Hence the midpoint is not in \(X_2\), and

\[ \boxed{X_2\text{ is not convex}.} \]
The first quadrant is convex.
A single line segment leaving the set is enough to show nonconvexity.

2. Basic Convex Sets Defined by Linear Equalities and Inequalities

2.1 Hyperplanes

Hyperplane
For \(\mathbf{a}\in\mathbb{R}^n\) and \(b\in\mathbb{R}\), \[ H=\{\mathbf{x}\in\mathbb{R}^n:\mathbf{a}^\top\mathbf{x}=b\}. \] For a genuine hyperplane, one normally assumes \(\mathbf{a}\neq0\).
Proposition — A hyperplane is convex
Let \(\mathbf{x},\mathbf{y}\in H\). Then \[ \mathbf{a}^\top\mathbf{x}=b, \qquad \mathbf{a}^\top\mathbf{y}=b. \] For \(\lambda\in[0,1]\), define \[ \mathbf{z}=\lambda\mathbf{x}+(1-\lambda)\mathbf{y}. \] Then \[ \begin{aligned} \mathbf{a}^\top\mathbf{z} &= \mathbf{a}^\top\bigl(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\bigr)\\ &= \lambda\mathbf{a}^\top\mathbf{x} +(1-\lambda)\mathbf{a}^\top\mathbf{y}\\ &= \lambda b+(1-\lambda)b=b. \end{aligned} \] Hence \(\mathbf{z}\in H\), so \(H\) is convex.

2.2 Halfspaces

Halfspace
A closed halfspace has the form \[ H_-=\{\mathbf{x}\in\mathbb{R}^n:\mathbf{a}^\top\mathbf{x}\le b\}. \]

Take \(\mathbf{x},\mathbf{y}\in H_-\). Then

\[ \mathbf{a}^\top\mathbf{x}\le b, \qquad \mathbf{a}^\top\mathbf{y}\le b. \]

For \(\mathbf{z}=\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\),

\[ \begin{aligned} \mathbf{a}^\top\mathbf{z} &= \lambda\mathbf{a}^\top\mathbf{x} + (1-\lambda)\mathbf{a}^\top\mathbf{y}\\ &\le \lambda b+(1-\lambda)b\\ &=b. \end{aligned} \]

Thus \(\mathbf{z}\in H_-\), so every halfspace is convex.

Any segment joining two points in the same halfspace remains in the halfspace.

2.3 A useful \(\ell_\infty\)-ball example

The set

\[ B_\infty \left( \begin{pmatrix}1\\1\end{pmatrix}, 1 \right) = \left\{ \mathbf{x}\in\mathbb{R}^2: \max_{i=1,2}|x_i-1|\le1 \right\} \]

is exactly the square

\[ \boxed{[0,2]\times[0,2].} \]

For instance, \((2,1)\) belongs to the set because \(\max(|2-1|,|1-1|)=1\), while \((3,1)\) does not.

3. Sets Defined by Norms

The \(p\)-norm
For \(\mathbf{x}\in\mathbb{R}^n\), \[ \|\mathbf{x}\|_p = \begin{cases} \left(\displaystyle\sum_{i=1}^{n}|x_i|^p\right)^{1/p}, &1\le p<\infty,\\[1.2ex] \displaystyle\max_{1\le i\le n}|x_i|, &p=\infty. \end{cases} \]

Two norm properties will be used repeatedly:

\[ \boxed{ \|\mathbf{u}+\mathbf{v}\|_p \le \|\mathbf{u}\|_p+\|\mathbf{v}\|_p } \qquad\text{(triangle inequality)} \]

and

\[ \boxed{ \|\alpha\mathbf{u}\|_p = |\alpha|\,\|\mathbf{u}\|_p } \qquad\text{(positive homogeneity).} \]
Norm ball
For center \(\mathbf{c}\in\mathbb{R}^n\) and radius \(R\ge0\), \[ B_p(\mathbf{c},R) = \left\{ \mathbf{x}\in\mathbb{R}^n: \|\mathbf{x}-\mathbf{c}\|_p\le R \right\}. \]
Proposition 1 — Every norm ball is convex
Let \(\mathbf{x},\mathbf{y}\in B_p(\mathbf{c},R)\) and \(\lambda\in[0,1]\). Put \[ \mathbf{z}=\lambda\mathbf{x}+(1-\lambda)\mathbf{y}. \] Then \[ \begin{aligned} \|\mathbf{z}-\mathbf{c}\|_p &= \left\| \lambda(\mathbf{x}-\mathbf{c}) +(1-\lambda)(\mathbf{y}-\mathbf{c}) \right\|_p\\ &\le \left\|\lambda(\mathbf{x}-\mathbf{c})\right\|_p + \left\|(1-\lambda)(\mathbf{y}-\mathbf{c})\right\|_p\\ &= \lambda\|\mathbf{x}-\mathbf{c}\|_p +(1-\lambda)\|\mathbf{y}-\mathbf{c}\|_p\\ &\le \lambda R+(1-\lambda)R\\ &=R. \end{aligned} \] Therefore \(\mathbf{z}\in B_p(\mathbf{c},R)\).
In \(\mathbb{R}^2\): \(\ell_1\)-ball (diamond), \(\ell_2\)-ball (circle), \(\ell_\infty\)-ball (square).
The proof works for every norm because it uses only norm axioms.

4. Operations That Preserve Convexity of Sets

Once we know a few basic convex sets, we can build many new ones using operations that preserve convexity. For this course, the most useful operations are intersection, affine images, and inverse affine images.

4.1 Intersections

Proposition — Intersection
If \(X_1,\ldots,X_m\) are convex sets, then \[ \boxed{ \bigcap_{i=1}^{m}X_i } \] is convex.

Proof. Let

\[ \mathbf{z}_1,\mathbf{z}_2 \in \bigcap_{i=1}^{m}X_i \]

and let \(\lambda\in[0,1]\). Then, for every \(i\),

\[ \mathbf{z}_1,\mathbf{z}_2\in X_i. \]

Since \(X_i\) is convex,

\[ \lambda\mathbf{z}_1+(1-\lambda)\mathbf{z}_2\in X_i \qquad \text{for every }i. \]

Therefore

\[ \boxed{ \lambda\mathbf{z}_1+(1-\lambda)\mathbf{z}_2 \in \bigcap_{i=1}^{m}X_i. } \]
Important example — Polyhedra
A polyhedron \[ P=\{\mathbf{x}\in\mathbb{R}^n:A\mathbf{x}\le\mathbf{b}\} \] is an intersection of halfspaces. If the rows of \(A\) are \(\mathbf{a}_1^\top,\ldots,\mathbf{a}_m^\top\), then \[ P = \bigcap_{i=1}^{m} \{\mathbf{x}:\mathbf{a}_i^\top\mathbf{x}\le b_i\}. \] Since every halfspace is convex, every polyhedron is convex.

4.2 Affine images

Proposition — Affine image
Let \(X\subseteq\mathbb{R}^n\) be convex and \[ f(\mathbf{x})=A\mathbf{x}+\mathbf{b}. \] Then \[ f(X)=\{A\mathbf{x}+\mathbf{b}:\mathbf{x}\in X\} \] is convex.

Proof. Let \(\mathbf{y}_1,\mathbf{y}_2\in f(X)\). Then there exist \(\mathbf{x}_1,\mathbf{x}_2\in X\) such that

\[ \mathbf{y}_1=A\mathbf{x}_1+\mathbf{b}, \qquad \mathbf{y}_2=A\mathbf{x}_2+\mathbf{b}. \]

For \(\lambda\in[0,1]\), convexity of \(X\) gives

\[ \bar{\mathbf{x}} = \lambda\mathbf{x}_1+(1-\lambda)\mathbf{x}_2 \in X. \]

Moreover,

\[ \begin{aligned} A\bar{\mathbf{x}}+\mathbf{b} &= A\bigl(\lambda\mathbf{x}_1+(1-\lambda)\mathbf{x}_2\bigr)+\mathbf{b}\\ &= \lambda(A\mathbf{x}_1+\mathbf{b}) + (1-\lambda)(A\mathbf{x}_2+\mathbf{b})\\ &= \lambda\mathbf{y}_1+(1-\lambda)\mathbf{y}_2. \end{aligned} \]

Hence the convex combination belongs to \(f(X)\).

4.3 Inverse affine images

Proposition — Inverse affine image
Let \(X\subseteq\mathbb{R}^n\) be convex and define \[ \mathcal{A}(\mathbf{y})=A\mathbf{y}+\mathbf{b}. \] Then \[ \mathcal{A}^{-1}(X) = \{\mathbf{y}:A\mathbf{y}+\mathbf{b}\in X\} \] is convex.

Proof. If \(\mathbf{y}_1,\mathbf{y}_2\in\mathcal{A}^{-1}(X)\), then

\[ A\mathbf{y}_1+\mathbf{b}\in X, \qquad A\mathbf{y}_2+\mathbf{b}\in X. \]

For \(\bar{\mathbf{y}}=\lambda\mathbf{y}_1+(1-\lambda)\mathbf{y}_2\),

\[ A\bar{\mathbf{y}}+\mathbf{b} = \lambda(A\mathbf{y}_1+\mathbf{b}) + (1-\lambda)(A\mathbf{y}_2+\mathbf{b}). \]

The right-hand side is a convex combination of two points in \(X\), hence belongs to \(X\). Therefore \(\bar{\mathbf{y}}\in\mathcal{A}^{-1}(X)\).

Other useful facts — no proof required here
Cartesian products of convex sets are convex, and weighted sums of convex sets are convex. These facts follow from the same idea: form a convex combination and check it component by component.
Not every set operation preserves convexity
Set difference does not preserve convexity. For example, \[ \mathbb{R}\setminus[0,1] = (-\infty,0)\cup(1,\infty) \] is not convex.

5. Convex Hull

Definition 3 — Convex hull
The convex hull of \(X\subseteq\mathbb{R}^n\) is the set of all finite convex combinations of points in \(X\): \[ \boxed{ \operatorname{conv}(X) = \left\{ \mathbf{y}\in\mathbb{R}^n: \mathbf{y}=\sum_{i=1}^{k}\lambda_i\mathbf{x}_i,\; \lambda_i\ge0,\; \sum_{i=1}^{k}\lambda_i=1,\; \mathbf{x}_i\in X \right\}. } \]
Fundamental properties of the convex hull
  1. \(\operatorname{conv}(X)\) is convex, even when \(X\) is not.
  2. If \(X\) is convex, then \(\operatorname{conv}(X)=X\).
  3. \(\operatorname{conv}(X)\) is the smallest convex set containing \(X\).

Why is it the smallest convex superset?

First, every \(\mathbf{x}\in X\) is itself a convex combination with one point, so

\[ X\subseteq\operatorname{conv}(X). \]

Now suppose \(C\) is any convex set with \(X\subseteq C\). Since \(C\) contains all convex combinations of its elements, it contains every convex combination of points of \(X\). Therefore

\[ \operatorname{conv}(X)\subseteq C. \]

Thus no smaller convex set can contain \(X\).

Example
Let \[ X=[0,1]\cup[2,3]. \] The original set has a gap between \(1\) and \(2\), so it is not convex. Filling in all line segments gives \[ \boxed{ \operatorname{conv}(X)=[0,3]. } \]
The convex hull fills the missing interval.

6. Combination Types and Cones

It is useful to distinguish several kinds of combinations of points \(\mathbf{x}_1,\ldots,\mathbf{x}_k\):

\[ \sum_{i=1}^{k}\lambda_i\mathbf{x}_i. \]
Combination Conditions on coefficients
Convex \(\lambda_i\ge0\) and \(\sum_i\lambda_i=1\)
Conic \(\lambda_i\ge0\)
Affine \(\sum_i\lambda_i=1\), coefficients may be negative
Linear \(\lambda_i\in\mathbb{R}\)
Cone
A set \(K\subseteq\mathbb{R}^n\) is a cone if \[ \mathbf{x}\in K,\ \alpha\ge0 \quad\Longrightarrow\quad \alpha\mathbf{x}\in K. \]

A set that is both a cone and a convex set is called a convex cone.

Examples
The first quadrant \[ K_1=\{(x_1,x_2):x_1\ge0,\ x_2\ge0\} \] is a convex cone. By contrast, \[ K_2=\{(x_1,x_2):x_1x_2\ge0\} \] is a cone but is not convex.
Why only a brief introduction?
For this course, the main concept is convexity. Cones become especially important later in more advanced topics such as conic and semidefinite optimization.

7. Convex Functions

Definition 5 — Convex function
Let \(f:\mathbb{R}^n\to\overline{\mathbb{R}}\), where \(\overline{\mathbb{R}}=\mathbb{R}\cup\{+\infty\}\). The function \(f\) is convex if:
  1. its effective domain \[ \operatorname{dom}(f) = \{\mathbf{x}:f(\mathbf{x})<+\infty\} \] is a convex set; and
  2. for every \(\mathbf{x},\mathbf{y}\in\operatorname{dom}(f)\) and \(\lambda\in[0,1]\), \[ \boxed{ f\bigl(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\bigr) \le \lambda f(\mathbf{x})+(1-\lambda)f(\mathbf{y}). } \]
Geometric meaning
Pick two points \((\mathbf{x},f(\mathbf{x}))\) and \((\mathbf{y},f(\mathbf{y}))\) on the graph. For a convex function, the straight chord joining these points lies on or above the graph.
\(f(\lambda\mathbf{x}+(1-\lambda)\mathbf{y})\) is no larger than the corresponding weighted average of \(f(\mathbf{x})\) and \(f(\mathbf{y})\).

7.1 Example: \(f(x)=x^2\)

The domain is \(\mathbb{R}\), which is convex. For \(x,y\in\mathbb{R}\) and \(\lambda\in[0,1]\),

\[ \begin{aligned} &\lambda x^2+(1-\lambda)y^2 -\bigl(\lambda x+(1-\lambda)y\bigr)^2\\ &\qquad =\lambda(1-\lambda)(x-y)^2 \ge0. \end{aligned} \]

Therefore

\[ \boxed{ \bigl(\lambda x+(1-\lambda)y\bigr)^2 \le \lambda x^2+(1-\lambda)y^2, } \]

so \(f(x)=x^2\) is convex. In fact, the inequality is strict whenever \(x\neq y\) and \(\lambda\in(0,1)\), so \(x^2\) is strictly convex.

7.2 Example: \(f(x)=e^x\)

Since

\[ f''(x)=e^x>0 \qquad\forall x\in\mathbb{R}, \]

\(e^x\) is strictly convex on \(\mathbb{R}\).

Exercise
Verify directly that \[ e^{\lambda x+(1-\lambda)y} \le \lambda e^x+(1-\lambda)e^y. \] Later this follows immediately from Jensen’s inequality.

7.3 Example: affine functions

Let

\[ f(\mathbf{x})=\mathbf{a}^{\top}\mathbf{x}+b. \]

Then

\[ \begin{aligned} f\bigl(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\bigr) &= \mathbf{a}^{\top} \bigl(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\bigr)+b\\ &= \lambda(\mathbf{a}^{\top}\mathbf{x}+b) +(1-\lambda)(\mathbf{a}^{\top}\mathbf{y}+b)\\ &= \lambda f(\mathbf{x})+(1-\lambda)f(\mathbf{y}). \end{aligned} \]

Thus every affine function satisfies the convexity inequality with equality. It is therefore both convex and concave.

Connection to optimization
Convex sets describe the geometry of feasible regions, while convex functions describe the geometry of objectives. Minimizing a convex function over a convex feasible set is the basic setting of convex optimization.

8. Two Useful Examples of Convex Functions

8.1 Norms are convex functions

Recall — Norm
A norm \(\|\cdot\|\) satisfies, among other properties, \[ \|\alpha\mathbf{x}\|=|\alpha|\,\|\mathbf{x}\| \] and \[ \|\mathbf{x}+\mathbf{y}\| \le \|\mathbf{x}\|+\|\mathbf{y}\|. \]
Proposition — Every norm is convex
For \(\lambda\in[0,1]\), \[ \begin{aligned} \|\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\| &\le \|\lambda\mathbf{x}\| + \|(1-\lambda)\mathbf{y}\|\\ &= \lambda\|\mathbf{x}\| +(1-\lambda)\|\mathbf{y}\|. \end{aligned} \] Thus every norm satisfies the convexity inequality.

Examples include the familiar \(p\)-norms

\[ \|\mathbf{x}\|_p = \left( \sum_{i=1}^{n}|x_i|^p \right)^{1/p}, \qquad p\ge1. \]

8.2 Indicator functions: encoding constraints in the objective

Indicator function
For a set \(C\subseteq\mathbb{R}^n\), \[ I_C(\mathbf{x}) = \begin{cases} 0, & \mathbf{x}\in C,\\ +\infty, & \mathbf{x}\notin C. \end{cases} \]

If \(C\) is convex, then \(I_C\) is a convex extended-valued function.

Why keep this concept?
It lets us rewrite a constrained problem \[ \min_{\mathbf{x}\in C}f(\mathbf{x}) \] as \[ \boxed{ \min_{\mathbf{x}} \bigl[f(\mathbf{x})+I_C(\mathbf{x})\bigr]. } \] This viewpoint will become useful later when we study proximal methods.

9. Strict Convexity, Strong Convexity, and Concavity

Strict convexity
A convex function \(f\) is strictly convex if, for \(\mathbf{x}\neq\mathbf{y}\) and \(\lambda\in(0,1)\), \[ f\bigl(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\bigr) < \lambda f(\mathbf{x})+(1-\lambda)f(\mathbf{y}). \]
Intuition
For a strictly convex function, the chord lies strictly above the graph between two distinct points.
Strong convexity
For \(\mu>0\), \(f\) is \(\mu\)-strongly convex if \[ \boxed{ \mathbf{x}\mapsto f(\mathbf{x})-\frac{\mu}{2}\|\mathbf{x}\|_2^2 } \] is convex.

Strong convexity means that the function has a definite amount of upward curvature. We will return to this idea when studying convergence of gradient methods.

Concavity
A function \(g\) is concave if \(-g\) is convex. Equivalently, \[ g\bigl(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\bigr) \ge \lambda g(\mathbf{x})+(1-\lambda)g(\mathbf{y}). \]

Typical examples are

\[ -x^2, \qquad \sqrt{x}\ (x\ge0), \qquad \log x\ (x>0). \]
Affine functions
Affine functions are both convex and concave because the defining inequality holds with equality.

9.1 Sums

  • The sum of convex functions is convex.
  • The sum of strictly convex functions is strictly convex.
  • If \(f\) is strongly convex and \(g\) is convex, then \(f+g\) is strongly convex.

10. Jensen’s Inequality

Jensen’s inequality
Let \(f:\mathbb{R}^n\to\overline{\mathbb{R}}\) be convex. For points \(\mathbf{x}_1,\ldots,\mathbf{x}_k\) in its domain and weights \(\lambda_i\ge0\) satisfying \[ \sum_{i=1}^{k}\lambda_i=1, \] we have \[ \boxed{ f\left(\sum_{i=1}^{k}\lambda_i\mathbf{x}_i\right) \le \sum_{i=1}^{k}\lambda_i f(\mathbf{x}_i). } \]

The two-point definition of convexity is exactly the case \(k=2\). The general finite form follows by induction.

For concave functions
If \(g\) is concave, the inequality reverses: \[ g\left(\sum_i\lambda_i\mathbf{x}_i\right) \ge \sum_i\lambda_i g(\mathbf{x}_i). \]

10.1 Arithmetic Mean–Geometric Mean Inequality

Let \(x_1,\ldots,x_n>0\). Since \(\log x\) is concave, Jensen’s inequality with \(\lambda_i=1/n\) gives

\[ \frac1n\sum_{i=1}^{n}\log x_i \le \log\left(\frac1n\sum_{i=1}^{n}x_i\right). \]

Using

\[ \frac1n\sum_{i=1}^{n}\log x_i = \log\left( \prod_{i=1}^{n}x_i \right)^{1/n}, \]

and the fact that \(\log\) is increasing,

\[ \boxed{ \left( \prod_{i=1}^{n}x_i \right)^{1/n} \le \frac1n\sum_{i=1}^{n}x_i. } \]
Interpretation
The geometric mean never exceeds the arithmetic mean.

11. Why Convexity Matters in Optimization

Key result — Local minimum = global minimum
Let \(f\) be convex on a convex set \(C\). If \(\mathbf{x}^\star\in C\) is a local minimum of \(f\) over \(C\), then \(\mathbf{x}^\star\) is also a global minimum.

Proof idea. Suppose \(\mathbf{x}^\star\) were only locally optimal and not globally optimal. Then there would exist \(\mathbf{y}\in C\) such that

\[ f(\mathbf{y}) < f(\mathbf{x}^\star). \]

Because \(C\) is convex, for every sufficiently small \(\lambda>0\),

\[ \mathbf{z}_\lambda = (1-\lambda)\mathbf{x}^\star+\lambda\mathbf{y} \in C \]

and \(\mathbf{z}_\lambda\) can be made arbitrarily close to \(\mathbf{x}^\star\). Convexity gives

\[ \begin{aligned} f(\mathbf{z}_\lambda) &\le (1-\lambda)f(\mathbf{x}^\star) + \lambda f(\mathbf{y})\\ &< f(\mathbf{x}^\star), \end{aligned} \]

which contradicts local optimality. Therefore every local minimum is global.

Another important consequence
If \(f\) is strictly convex on a convex feasible set, then it can have at most one global minimizer.
This is the main reason convexity is so valuable
For a general nonconvex problem, an algorithm may stop at a poor local minimum. In a convex optimization problem, local optimality is enough to guarantee global optimality.
