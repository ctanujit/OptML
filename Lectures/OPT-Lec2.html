Main idea
Many optimization problems have the form \[ \min_{\mathbf{x}} f(\mathbf{x}) \qquad\text{or}\qquad \max_{\mathbf{x}} f(\mathbf{x}), \] where \(\mathbf{x}=(x_1,\ldots,x_n)^\top\in\mathbb R^n\). Derivatives help us identify candidate solutions and determine whether they are minima, maxima, or saddle points.

1. Local and Global Extrema

Let

\[ f:D\subseteq\mathbb R^n\rightarrow \mathbb R. \]

A point \(\mathbf{x}_0\in D\) is a local minimum if there exists \(\delta>0\) such that

\[ f(\mathbf{x})\geq f(\mathbf{x}_0) \]

for every feasible \(\mathbf{x}\) satisfying

\[ \|\mathbf{x}-\mathbf{x}_0\|<\delta. \]

Similarly, \(\mathbf{x}_0\) is a local maximum if

\[ f(\mathbf{x})\leq f(\mathbf{x}_0) \]

for every feasible \(\mathbf{x}\) sufficiently close to \(\mathbf{x}_0\).

Global extrema

A point \(\mathbf{x}_0\) is a global minimum if

\[ f(\mathbf{x}_0)\leq f(\mathbf{x}) \qquad \forall \mathbf{x}\in D. \]
\[ \boxed{\text{global minimum} \Longrightarrow \text{local minimum}} \] but the converse need not be true.

2. First-Order Necessary Condition

Suppose \(f\) is differentiable and \(\mathbf{x}_0\) is an interior point of the domain. If \(\mathbf{x}_0\) is a local maximum or local minimum, then

\[ \boxed{\nabla f(\mathbf{x}_0)=\mathbf 0.} \]

Equivalently,

\[ \frac{\partial f}{\partial x_i}(\mathbf{x}_0)=0, \qquad i=1,\ldots,n. \]

A point satisfying \(\nabla f(\mathbf{x}_0)=0\) is called a stationary point or critical point.

Important warning
The condition \(\nabla f(\mathbf{x}_0)=0\) is necessary for an unconstrained interior extremum, but it is not sufficient. For example, for \[ f(x)=x^3, \] we have \(f'(0)=0\), but \(x=0\) is neither a local minimum nor a local maximum.

Why must the gradient vanish?

Suppose \(\mathbf{x}_0\) is a local minimum. Choose any direction \(\mathbf d\) and define

\[ \phi(t)=f(\mathbf{x}_0+t\mathbf d). \]

Since \(\mathbf{x}_0\) is a local minimum of \(f\), \(t=0\) is a local minimum of \(\phi\). Hence

\[ \phi'(0)=0. \]

By the chain rule,

\[ \phi'(0) = \nabla f(\mathbf{x}_0)^\top\mathbf d. \]

Therefore

\[ \nabla f(\mathbf{x}_0)^\top\mathbf d=0 \]

for every direction \(\mathbf d\). The only vector orthogonal to every direction is the zero vector, hence

\[ \boxed{\nabla f(\mathbf{x}_0)=0.} \]

3. Functions of Two Variables

Consider

\[ f:\mathbb R^2\to\mathbb R. \]

Suppose \((x_0,y_0)\) is a stationary point:

\[ f_x(x_0,y_0)=0, \qquad f_y(x_0,y_0)=0. \]

The Hessian matrix is

\[ H_f(x_0,y_0) = \begin{pmatrix} f_{xx} & f_{xy}\\ f_{yx} & f_{yy} \end{pmatrix}_{(x_0,y_0)}. \]

If \(f\in C^2\), then \(f_{xy}=f_{yx}\), so the Hessian is symmetric.

Define

\[ \boxed{ \Delta = \det H_f(x_0,y_0) = f_{xx}f_{yy}-f_{xy}^{\,2}. } \]

Second-Derivative Test

\(\Delta\) \(f_{xx}\) Conclusion
\(>0\) \(>0\) Strict local minimum
\(>0\) \(<0\) Strict local maximum
\(<0\) — Saddle point
\(=0\) — Test inconclusive

Equivalently, in terms of the Hessian,

\[ \boxed{ \begin{aligned} H_f\succ0 &\Longrightarrow \text{strict local minimum},\\ H_f\prec0 &\Longrightarrow \text{strict local maximum},\\ H_f\text{ indefinite} &\Longrightarrow \text{saddle point}. \end{aligned}} \]

4. Why Does the Hessian Determine the Local Shape?

Let

\[ \mathbf z= \begin{pmatrix} h\\ k \end{pmatrix}. \]

A second-order Taylor expansion around a stationary point \(\mathbf x_0\) gives

\[ f(\mathbf x_0+\mathbf z) = f(\mathbf x_0) + \nabla f(\mathbf x_0)^\top\mathbf z + \frac12 \mathbf z^\top H_f(\mathbf x_0)\mathbf z + o(\|\mathbf z\|^2). \]

Since \(\nabla f(\mathbf x_0)=0\),

\[ \boxed{ f(\mathbf x_0+\mathbf z)-f(\mathbf x_0) = \frac12\mathbf z^\top H_f(\mathbf x_0)\mathbf z + o(\|\mathbf z\|^2). } \]

Thus, sufficiently close to \(\mathbf x_0\), the sign of the change in \(f\) is controlled by the quadratic form

\[ \mathbf z^\top H_f(\mathbf x_0)\mathbf z. \]

Positive definite Hessian

If \(H_f(\mathbf x_0)\succ0\), then

\[ \mathbf z^\top H_f(\mathbf x_0)\mathbf z>0 \qquad\forall \mathbf z\neq0. \]

Hence nearby points have larger function values:

\[ f(\mathbf x_0+\mathbf z)>f(\mathbf x_0), \]

so \(\mathbf x_0\) is a strict local minimum.

Negative definite Hessian

If \(H_f(\mathbf x_0)\prec0\), then

\[ \mathbf z^\top H_f(\mathbf x_0)\mathbf z<0 \qquad\forall \mathbf z\neq0. \]

Hence nearby points have smaller function values, so \(\mathbf x_0\) is a strict local maximum.

Indefinite Hessian

If \(H_f(\mathbf x_0)\) is indefinite, then there are directions \(\mathbf d_1,\mathbf d_2\) such that

\[ \mathbf d_1^\top H_f\mathbf d_1>0, \qquad \mathbf d_2^\top H_f\mathbf d_2<0. \]

The function increases in one direction and decreases in another. Hence \(\mathbf x_0\) is a saddle point.

Example: a saddle point

Consider

\[ f(x,y)=x^2-y^2. \]

Then

\[ \nabla f(x,y)= \begin{pmatrix} 2x\\ -2y \end{pmatrix}, \]

so the only stationary point is \((0,0)\). The Hessian is

\[ H_f= \begin{pmatrix} 2&0\\ 0&-2 \end{pmatrix}, \]

and

\[ \Delta=(2)(-2)=-4<0. \]

Therefore \(H_f\) is indefinite and \((0,0)\) is a saddle point.

Indeed, along \(y=0\),

\[ f(x,0)=x^2>0, \]

while along \(x=0\),

\[ f(0,y)=-y^2<0. \]

Why does \(\Delta<0\) mean indefinite?

Let the eigenvalues of the symmetric Hessian be \(\lambda_1,\lambda_2\). Then

\[ \det(H_f)=\lambda_1\lambda_2. \]

If \(\Delta<0\), then

\[ \lambda_1\lambda_2<0, \]

so one eigenvalue is positive and the other is negative. Therefore the Hessian is indefinite.

Why does \(\Delta>0\) also require \(f_{xx}\)?

If \(\Delta>0\), the eigenvalues have the same sign. To determine whether both are positive or both are negative, we use \(f_{xx}\):

\[ \Delta>0,\ f_{xx}>0 \Longrightarrow H_f\succ0, \] \[ \Delta>0,\ f_{xx}<0 \Longrightarrow H_f\prec0. \]

What if \(\Delta=0\)?

The second-derivative test is inconclusive.

For example,

\[ f(x,y)=x^4+y^4 \]

has \(H_f(0,0)=0\), but \((0,0)\) is a strict local minimum.

By contrast,

\[ f(x,y)=x^4-y^4 \]

also has \(H_f(0,0)=0\), but \((0,0)\) is a saddle point.

\[ \boxed{\Delta=0\Longrightarrow \text{further investigation is needed}.} \]

Before extending the Hessian test to \(n\) variables, we now apply the gradient and Hessian ideas to a concrete two-variable function. The example also shows how these quantities can be visualized and computed in Python.

5. Worked Example: Visualizing a Function, Its Gradient, and Its Hessian

To visualize functions and gradients, consider the function

\[ \boxed{f(x,y)=1-e^{-(x-1)^2}\sin(\pi y)}, \qquad x\in[0,2],\;y\in[0,1]. \]
Figure 1. Visualization of the function and its gradient field.

5.1 Gradient

The gradient collects the first partial derivatives:

\[ \nabla f(x,y) = \begin{pmatrix} \frac{\partial f}{\partial x}\\[4pt] \frac{\partial f}{\partial y} \end{pmatrix}. \]

For this function,

\[ \frac{\partial f}{\partial x} = 2(x-1)e^{-(x-1)^2}\sin(\pi y), \] \[ \frac{\partial f}{\partial y} = -\pi e^{-(x-1)^2}\cos(\pi y). \]

Hence

\[ \boxed{ \nabla f(x,y) = \begin{pmatrix} 2(x-1)e^{-(x-1)^2}\sin(\pi y)\\[4pt] -\pi e^{-(x-1)^2}\cos(\pi y) \end{pmatrix}. } \]
Interpretation. The gradient \(\nabla f\) points in the direction of steepest local increase. Therefore \(-\nabla f\) is the steepest local descent direction. For any point where \(\nabla f\neq0\), moving a sufficiently small distance in the direction \(-\nabla f\) decreases the function value.

5.2 What the Contour Plot Shows

  1. The gradient vectors are perpendicular to the level curves (contours) of the function.
  2. The negative gradient gives the direction of steepest local decrease.
  3. “Steepest locally” does not necessarily mean “best overall direction” toward the global minimizer. Optimization algorithms must also choose an appropriate step size and may use curvature information.

5.3 Hessian

The Hessian contains all second-order partial derivatives:

\[ H_f(x,y) = \begin{pmatrix} f_{xx} & f_{xy}\\ f_{yx} & f_{yy} \end{pmatrix}. \]

For this function,

\[ f_{xx} = 2e^{-(x-1)^2}\sin(\pi y) \left[1-2(x-1)^2\right], \] \[ f_{xy}=f_{yx} = 2\pi(x-1)e^{-(x-1)^2}\cos(\pi y), \] \[ f_{yy} = \pi^2e^{-(x-1)^2}\sin(\pi y). \]

Therefore,

\[ \boxed{ H_f(x,y)= \begin{pmatrix} 2e^{-(x-1)^2}\sin(\pi y)[1-2(x-1)^2] & 2\pi(x-1)e^{-(x-1)^2}\cos(\pi y) \\[6pt] 2\pi(x-1)e^{-(x-1)^2}\cos(\pi y) & \pi^2e^{-(x-1)^2}\sin(\pi y) \end{pmatrix}. } \]

5.4 Hessian at \((0.1,0)\)

At \((x,y)=(0.1,0)\), \[ H_f(0.1,0) \approx \begin{pmatrix} 0.000000 & -2.515613\\ -2.515613 & 0.000000 \end{pmatrix}. \] Its eigenvalues are approximately \[ \boxed{\lambda_1\approx 2.515613, \qquad \lambda_2\approx -2.515613.} \] Because one eigenvalue is positive and the other is negative, the Hessian is indefinite at this point.

The gradient at the same point is

\[ \nabla f(0.1,0) \approx \begin{pmatrix} 0.000000\\ -1.397563 \end{pmatrix}. \]
Important distinction. Although the Hessian is indefinite at \((0.1,0)\), this point is not a saddle point, because \(\nabla f(0.1,0)\neq0\). For the usual second-order saddle-point classification, we first require a stationary point: \(\nabla f=0\). Here, an indefinite Hessian simply tells us that the local curvature has opposite signs in different directions.

5.5 Python Code

The following Python code reproduces the 3D function plot, contour/gradient plot, symbolic gradient, Hessian, and Hessian eigenvalues. 

import numpy as np
import sympy as sp
import matplotlib.pyplot as plt
x, y = sp.symbols("x y", real=True)
f = 1 - sp.exp(-(x - 1)**2) * sp.sin(sp.pi * y)
f_num = sp.lambdify((x, y), f, "numpy")
x_grid = np.linspace(0, 2, 121)
y_grid = np.linspace(0, 1, 81)
X, Y = np.meshgrid(x_grid, y_grid)
Z = f_num(X, Y)

fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection="3d")
ax.plot_surface(X, Y, Z, linewidth=0.25, antialiased=True)
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.set_zlabel("f(x,y)")
ax.set_title(r"$f(x,y)=1-e^{-(x-1)^2}\sin(\pi y)$")
plt.tight_layout()
plt.show()

grad_f = sp.Matrix([
    sp.diff(f, x),
    sp.diff(f, y)
])

print("Gradient:")
sp.pprint(grad_f)

fx = sp.diff(f, x)
fy = sp.diff(f, y)

fx_num = sp.lambdify((x, y), fx, "numpy")
fy_num = sp.lambdify((x, y), fy, "numpy")

# ------------------------------------------------------------
# Cartesian grid and contour + gradient vectors
# ------------------------------------------------------------
xq = np.arange(0, 2.0001, 0.1)
yq = np.arange(0, 1.0001, 0.1)
Xq, Yq = np.meshgrid(xq, yq)

Gx = fx_num(Xq, Yq)
Gy = fy_num(Xq, Yq)

fig, ax = plt.subplots(figsize=(8, 6))
ax.contour(X, Y, Z, levels=12)
ax.quiver(Xq, Yq, Gx, Gy)
ax.set_xlim(0, 2)
ax.set_ylim(0, 1)
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.set_title("Contours with gradient vectors")
plt.tight_layout()
plt.show()

# ------------------------------------------------------------
# Hessian and eigenvalues at (0.1, 0)
# ------------------------------------------------------------
H = sp.hessian(f, (x, y))

print("\nHessian:")
sp.pprint(H)

H_at_point = H.subs({x: 0.1, y: 0})
print("\nHessian at (0.1, 0):")
sp.pprint(sp.N(H_at_point))

H_np = np.array(H_at_point.evalf(), dtype=float)
eigenvalues = np.linalg.eigvals(H_np)

print("\nEigenvalues at (0.1, 0):")
print(eigenvalues)

# Optional: gradient at the same point
grad_at_point = grad_f.subs({x: 0.1, y: 0})
print("\nGradient at (0.1, 0):")
sp.pprint(sp.N(grad_at_point))

# Note:
# An indefinite Hessian at a point where grad f != 0 does NOT mean that
# the point is a saddle point. It only indicates mixed local curvature.

The Python version uses SymPy for symbolic differentiation, NumPy for numerical arrays/eigenvalues, and Matplotlib for plotting.

6. Extension to \(n\) Variables

Suppose

\[ f:\mathbb R^n\to\mathbb R \]

is twice continuously differentiable and

\[ \nabla f(\mathbf x_0)=0. \]

The Hessian is

\[ H_f(\mathbf x_0) = \left[ \frac{\partial^2 f}{\partial x_i\partial x_j} \right]_{i,j=1}^n. \]

Then

\[ \boxed{ \begin{aligned} H_f(\mathbf x_0)\succ0 &\Rightarrow \mathbf x_0\text{ is a strict local minimum},\\ H_f(\mathbf x_0)\prec0 &\Rightarrow \mathbf x_0\text{ is a strict local maximum},\\ H_f(\mathbf x_0)\text{ indefinite} &\Rightarrow \mathbf x_0\text{ is a saddle point}. \end{aligned}} \]

If the Hessian is only positive semidefinite or negative semidefinite, the test may be inconclusive.

Eigenvalue interpretation

Because a Hessian of a \(C^2\) function is symmetric,

\[ H_f=Q\Lambda Q^\top, \]

where

\[ \Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_n). \]

Then

\[ \mathbf z^\top H_f\mathbf z = \sum_{i=1}^n \lambda_i u_i^2, \qquad \mathbf u=Q^\top\mathbf z. \]
Eigenvalues of \(H_f\) Classification
\(\lambda_i>0\) for all \(i\) Positive definite
\(\lambda_i<0\) for all \(i\) Negative definite
Both positive and negative eigenvalues Indefinite

7. Constrained Optimization and Lagrange Multipliers

Suppose we want to optimize

\[ f(x,y) \]

subject to

\[ g(x,y)=0. \]

Under a constraint, the optimum can occur at a point where \(\nabla f\neq0\). We therefore use the geometry of the feasible set.

Geometric idea

The equation \(g(x,y)=0\) defines a feasible curve, while \(f(x,y)=c\) defines a level curve of the objective.

At a regular constrained optimum, the level curve of \(f\) is tangent to the constraint curve. Therefore their normal vectors are parallel:

\[ \nabla f(x^\star,y^\star) = \mu\nabla g(x^\star,y^\star). \]

Equivalently, with a different sign convention,

\[ \boxed{ \nabla f(x^\star,y^\star) + \lambda\nabla g(x^\star,y^\star) =0. } \]

Lagrange Multiplier Theorem

Suppose \(f\) and \(g\) are continuously differentiable, \((x^\star,y^\star)\) is a local constrained optimum, and

\[ g(x^\star,y^\star)=0. \]

Assume also the regularity condition

\[ \boxed{\nabla g(x^\star,y^\star)\neq0.} \]

Then there exists a scalar \(\lambda\) such that

\[ \boxed{ \nabla f(x^\star,y^\star) + \lambda\nabla g(x^\star,y^\star) =0. } \]

Together with the constraint, this yields

\[ \begin{cases} f_x+\lambda g_x=0,\\ f_y+\lambda g_y=0,\\ g(x,y)=0. \end{cases} \]

The Lagrangian

Define

\[ \boxed{ \mathcal L(x,y,\lambda) = f(x,y)+\lambda g(x,y). } \]

The first-order conditions are

\[ \frac{\partial\mathcal L}{\partial x}=0, \qquad \frac{\partial\mathcal L}{\partial y}=0, \qquad \frac{\partial\mathcal L}{\partial\lambda}=g(x,y)=0. \]

Why are the gradients parallel?

Suppose the feasible curve is parameterized by \(\mathbf x(t)\) and satisfies

\[ g(\mathbf x(t))=0. \]

Differentiating gives

\[ \nabla g(\mathbf x(t))^\top\mathbf x'(t)=0. \]

Thus the tangent vector \(\mathbf x'(t)\) is orthogonal to \(\nabla g\).

At a constrained optimum,

\[ \frac{d}{dt}f(\mathbf x(t))=0, \]

so

\[ \nabla f(\mathbf x(t))^\top\mathbf x'(t)=0. \]

Therefore both \(\nabla f\) and \(\nabla g\) are normal to the same tangent direction. In \(\mathbb R^2\), they must therefore be parallel.

Example

Maximize

\[ f(x,y)=xy \]

subject to

\[ x^2+y^2=1. \]

Write

\[ g(x,y)=x^2+y^2-1. \]

The Lagrangian is

\[ \mathcal L = xy+\lambda(x^2+y^2-1). \]

The first-order conditions are

\[ y+2\lambda x=0, \] \[ x+2\lambda y=0, \] \[ x^2+y^2=1. \]

Solving gives candidate points with

\[ x=\pm\frac1{\sqrt2}, \qquad y=\pm\frac1{\sqrt2}, \]

with the signs either equal or opposite. Evaluating \(f\),

\[ f_{\max}=\frac12, \qquad f_{\min}=-\frac12. \]

Several equality constraints

Suppose

\[ \min_{\mathbf x} f(\mathbf x) \]

subject to

\[ g_i(\mathbf x)=0, \qquad i=1,\ldots,m. \]

Define

\[ \boxed{ \mathcal L(\mathbf x,\boldsymbol\lambda) = f(\mathbf x) + \sum_{i=1}^m \lambda_i g_i(\mathbf x). } \]

The first-order conditions are

\[ \boxed{ \nabla f(\mathbf x) + \sum_{i=1}^m \lambda_i\nabla g_i(\mathbf x) =0 } \]

together with

\[ \boxed{ g_i(\mathbf x)=0, \qquad i=1,\ldots,m. } \]

Geometrically,

\[ \nabla f \in \operatorname{span} \{ \nabla g_1,\ldots,\nabla g_m \}. \]

For the standard theorem, the active constraint gradients should satisfy an appropriate independence condition.

Existence of global extrema

By the Weierstrass theorem, if \(f\) is continuous and the feasible set \(S\) is nonempty and compact, then \(f\) attains both a global minimum and a global maximum on \(S\).

In \(\mathbb R^n\), compactness is equivalent to being closed and bounded.

If \(S\) is nonempty, closed, and bounded, and \(f\) is continuous, then \(f\) attains an absolute minimum and maximum on \(S\).

8. Matrix Calculus for Optimization

Let

\[ \mathbf x= \begin{pmatrix} x_1\\ \vdots\\ x_n \end{pmatrix}. \]

For a scalar-valued function \(f\),

\[ \boxed{ \nabla_{\mathbf x}f = \begin{pmatrix} \frac{\partial f}{\partial x_1}\\ \vdots\\ \frac{\partial f}{\partial x_n} \end{pmatrix}. } \]

Linear function

Let

\[ f(\mathbf x)=\mathbf a^\top\mathbf x. \]

Then

\[ \boxed{ \nabla_{\mathbf x}(\mathbf a^\top\mathbf x)=\mathbf a. } \]

Likewise,

\[ \boxed{ \nabla_{\mathbf x}(\mathbf x^\top\mathbf a)=\mathbf a. } \]

Linear vector map

Let

\[ \mathbf y=A\mathbf x, \qquad A\in\mathbb R^{m\times n}. \]

With the standard Jacobian convention,

\[ \boxed{ \frac{\partial(A\mathbf x)} {\partial\mathbf x^\top} =A. } \]
Different textbooks use slightly different Jacobian conventions. It is useful to state the convention explicitly in teaching material.

Quadratic form

Consider

\[ f(\mathbf x)=\mathbf x^\top A\mathbf x. \]

The general identity is

\[ \boxed{ \nabla_{\mathbf x} (\mathbf x^\top A\mathbf x) = (A+A^\top)\mathbf x. } \]

Derivation

Write

\[ f(\mathbf x) = \sum_{i=1}^n \sum_{j=1}^n a_{ij}x_i x_j. \]

Differentiating with respect to \(x_k\),

\[ \frac{\partial f}{\partial x_k} = \sum_{j=1}^n a_{kj}x_j + \sum_{i=1}^n a_{ik}x_i. \]

The first term is the \(k\)-th component of \(A\mathbf x\), and the second is the \(k\)-th component of \(A^\top\mathbf x\). Hence

\[ \boxed{ \nabla f = A\mathbf x+A^\top\mathbf x = (A+A^\top)\mathbf x. } \]

Symmetric case

If \(A=A^\top\), then

\[ \boxed{ \nabla_{\mathbf x} (\mathbf x^\top A\mathbf x) = 2A\mathbf x. } \]
Common mistake
The formula \[ \nabla(\mathbf x^\top A\mathbf x)=2A\mathbf x \] is valid only when \(A\) is symmetric. In general, \[ \nabla(\mathbf x^\top A\mathbf x)=(A+A^\top)\mathbf x. \]

Hessian of a quadratic form

Since

\[ \nabla(\mathbf x^\top A\mathbf x) = (A+A^\top)\mathbf x, \]

we obtain

\[ \boxed{ \nabla^2(\mathbf x^\top A\mathbf x) = A+A^\top. } \]

If \(A\) is symmetric,

\[ \boxed{ \nabla^2(\mathbf x^\top A\mathbf x) = 2A. } \]

Important optimization example

Consider

\[ f(\mathbf x) = \frac12\mathbf x^\top A\mathbf x - \mathbf b^\top\mathbf x, \qquad A=A^\top. \]

Then

\[ \nabla f(\mathbf x) = A\mathbf x-\mathbf b. \]

A stationary point satisfies

\[ A\mathbf x^\star=\mathbf b. \]

If \(A\succ0\), then

\[ \nabla^2f=A\succ0, \]

so \(\mathbf x^\star\) is the unique global minimum.

This example connects \[ \text{calculus} \longrightarrow \text{linear algebra} \longrightarrow \text{optimization}. \]

9. Compact Summary

Unconstrained optimization

Step 1: Find stationary points:

\[ \nabla f(\mathbf x)=0. \]

Step 2: Compute the Hessian:

\[ H_f(\mathbf x). \]

Step 3: Classify:

\[ \begin{cases} H_f\succ0 &\Rightarrow \text{local minimum},\\ H_f\prec0 &\Rightarrow \text{local maximum},\\ H_f\text{ indefinite} &\Rightarrow \text{saddle point}. \end{cases} \]

For two variables

\[ \Delta=f_{xx}f_{yy}-f_{xy}^2. \]
Condition Conclusion
\(\Delta>0,\ f_{xx}>0\)Local minimum
\(\Delta>0,\ f_{xx}<0\)Local maximum
\(\Delta<0\)Saddle point
\(\Delta=0\)Inconclusive

Constrained optimization

\[ \boxed{ \nabla f+ \sum_{i=1}^m\lambda_i\nabla g_i=0, \qquad g_i(\mathbf x)=0. } \]
